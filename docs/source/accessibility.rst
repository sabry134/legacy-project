Accessibility Features
======================

This document explains how the GeneWeb-Python project includes technical features that improve accessibility for users with disabilities.

Accessibility Toolkit
---------------------

The system includes an accessibility toolkit designed to improve usability for people with visual or interaction limitations.  
This toolkit allows the interface to adapt to different accessibility needs without modifying the core system.

Available accessibility options include:

- **Daltonian (color-blind) mode** that adapts interface colors to improve readability for users with color vision deficiency.
- **High-contrast display mode** improving text visibility.
- **Accessible navigation options** enabling easier interaction with assistive technologies.
- **Customizable interface settings** allowing users to adjust the display according to their needs.

These options help ensure that the application remains usable for a wide range of users.

Accessible Interface Design
---------------------------

The user interface supports accessibility by providing:

- readable interface components
- adaptable display settings
- compatibility with assistive tools

These features allow users with visual impairments or accessibility requirements to interact with the system more comfortably.

Extensible Accessibility Support
--------------------------------

Thanks to the modular architecture of GeneWeb-Python, accessibility features can be extended or improved easily.

New accessibility modules can be added without modifying the core system logic.  
This makes it possible to introduce additional accessibility tools in the future depending on user needs.

Conclusion
----------

The application integrates accessibility features such as color-blind display modes, customizable visual settings, and adaptable interface components.  
These elements ensure that the system can be used by people with different accessibility requirements.
